# Scout issues

Public issue tracker for **Scout**, the wireless debug probe from Ohmic Test Systems,
and its VS Code extension. This repository holds issues only; it has no source code.

## Report a problem

1. In VS Code, run **Scout: Report Issue**. It saves a local zip with logs, versions and
   redacted settings. Nothing is sent automatically.
2. Pick **Open GitHub issue**. It opens a prefilled bug form here.
3. Read the zip, remove anything you do not want to share, and attach it to the issue.

You can also email support@ohmic-test.com and attach the zip.

Do not post secrets, keys or private firmware.

Maintainers: see [TRIAGE.md](TRIAGE.md) for labels and the triage flow.
